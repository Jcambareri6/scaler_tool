Rediseña visualmente toda la aplicación existente utilizando un lenguaje visual moderno basado principalmente en **Glassmorphism**, manteniendo la estructura, navegación, jerarquía de información y funcionalidades actuales.

El objetivo es que la aplicación se sienta como una **plataforma SaaS de inteligencia artificial premium, moderna y tecnológica**, similar a productos actuales de AI, pero evitando el aspecto genérico de una plantilla.

### Dirección visual

Utiliza Glassmorphism como concepto principal:

* Superficies translúcidas y semitransparentes.
* Fondos con profundidad y degradados muy sutiles.
* Efecto de `backdrop-blur` en cards, paneles, modales y navegación cuando tenga sentido.
* Bordes extremadamente sutiles y luminosos.
* Sombras suaves y difusas.
* Capas visuales que generen sensación de profundidad.
* Transparencias controladas para evitar que la interfaz se vea saturada.
* Contraste suficiente para mantener una excelente legibilidad.

No convertir absolutamente todos los elementos en vidrio. El glassmorphism debe utilizarse estratégicamente para crear jerarquía visual.

### Fondo

Crear un background oscuro y sofisticado, orientado a productos de inteligencia artificial.

Utilizar:

* Base dark navy / charcoal.
* Gradientes radiales muy sutiles.
* Algunos halos o blobs de luz difuminados en el background.
* Diferentes niveles de profundidad.

Los efectos de luz deben ser muy discretos y elegantes. Evitar el típico diseño exagerado de "AI neon".

### Cards y contenedores

Transformar las cards existentes para que tengan apariencia de vidrio:

* Background semitransparente.
* `backdrop blur`.
* Border de 1px con baja opacidad.
* Border-radius moderno, aproximadamente 14–20px.
* Sombras suaves.
* Diferentes niveles de transparencia según la importancia del componente.

Las cards principales deben destacar ligeramente sobre el background, mientras que elementos secundarios pueden utilizar una transparencia mayor.

### Sidebar / navegación

Convertir el sidebar en un panel de vidrio integrado con el resto de la interfaz.

Debe:

* Mantener una navegación clara.
* Tener fondo translúcido.
* Utilizar blur.
* Tener un borde sutil.
* Diferenciar claramente el elemento activo.
* Utilizar un indicador visual elegante para la sección seleccionada.

Evitar un sidebar completamente sólido.

### Chat de IA

El chat debe ser uno de los elementos visualmente más importantes.

Diseñarlo como una experiencia de conversación moderna:

* Área de conversación limpia.
* Mensajes del usuario y de la IA claramente diferenciados.
* Burbujas/paneles con glassmorphism ligero.
* Input de mensaje grande y moderno.
* Botón de enviar destacado pero elegante.
* Estados de loading/generación.
* Indicadores visuales cuando la IA está utilizando una herramienta.
* Mostrar herramientas utilizadas de manera clara pero discreta.

El chat debe sentirse como el centro de control de toda la plataforma.

### Herramientas y agentes

Para agentes, tools, integraciones y proveedores, utilizar componentes visuales consistentes con el sistema glassmorphism.

Las herramientas pueden representarse mediante:

* Iconos.
* Cards compactas.
* Badges.
* Estados activos/inactivos.
* Indicadores de conexión.
* Pequeños efectos de iluminación.

Cuando una herramienta esté ejecutándose, utilizar una animación o estado visual sutil que indique actividad.

### Botones

Crear un sistema de botones moderno:

Primary:

* Gradiente o superficie ligeramente luminosa.
* Alto contraste.
* Sombra/glow muy sutil.

Secondary:

* Glassmorphism.
* Border sutil.
* Fondo semitransparente.

Ghost:

* Sin background.
* Hover elegante.

Evitar botones excesivamente grandes o con colores demasiado saturados.

### Inputs

Los inputs deben integrarse con el lenguaje glassmorphism:

* Background translúcido.
* Border sutil.
* Focus state claramente visible.
* Border/glow suave al recibir foco.
* Placeholder con contraste adecuado.

### Modales y overlays

Los modales deben utilizar una capa de glassmorphism más intensa:

* Fondo translúcido.
* Blur fuerte del contenido detrás.
* Border sutil.
* Sombra profunda.
* Bordes redondeados.

El contenido debe seguir siendo extremadamente legible.

### Tipografía

Utilizar una tipografía moderna y limpia, preferentemente una sans-serif contemporánea.

La jerarquía tipográfica debe ser clara:

* Headings fuertes.
* Subheadings discretos.
* Body text altamente legible.
* Metadata con menor contraste.

Evitar utilizar demasiados tamaños o pesos diferentes.

### Sistema de diseño

Crear consistencia visual entre toda la aplicación.

Definir visualmente:

* Background colors.
* Surface colors.
* Glass surfaces.
* Borders.
* Shadows.
* Border radius.
* Typography.
* Buttons.
* Inputs.
* Cards.
* Badges.
* Status indicators.
* Icons.
* Hover states.
* Focus states.
* Active states.
* Loading states.

Utilizar una escala coherente de spacing y radius.

### Principio importante

No modificar innecesariamente la arquitectura UX existente.

**Mantener la estructura, navegación, funcionalidades, contenido y jerarquía actual de la aplicación.**

El objetivo es realizar un **rediseño visual profundo**, no crear una aplicación diferente.

La interfaz final debe transmitir:

**AI Platform + Premium SaaS + Glassmorphism + Modern Developer Tool**

Debe sentirse profesional, sofisticada, rápida y tecnológica.

Evitar:

* Exceso de neon.
* Gradientes demasiado fuertes.
* Exceso de blur.
* Cards gigantes.
* Sombras pesadas.
* Efectos visuales innecesarios.
* Diseño excesivamente futurista.
* Apariencia de landing page.
* Glassmorphism aplicado indiscriminadamente.

Priorizar siempre **usabilidad, legibilidad y jerarquía visual por encima del efecto visual**.

El resultado debería parecer un producto de IA real listo para producción, no un concepto experimental de Dribbble.
