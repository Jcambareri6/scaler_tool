# Direccion visual

Este metodo sirve para cualquier tema: interpretalo segun el guion, no copies ningun video ni canal.

No ilustres lo que dice la voz: demostralo. Para cada tramo preguntate que tiene que entender el espectador y que experimento visual lo prueba.

- ILUSTRAR: "un reactor, porque se habla de un reactor".
- DEMOSTRAR: "dos columnas de personas sobre una balanza: la segunda es tan pesada que la hunde".

## Una escena, una demostracion

Un escenario dibujado cubre de 15 a 30 segundos de voz. Tiene pocos objetos grandes, un solo lugar, un cambio nuevo cada 3 a 6 segundos y una estructura:

1. **Planteo:** aparece el sistema y empieza a moverse.
2. **Tension:** algo se prepara, se acumula o empeora a la vista.
3. **Remate:** en la palabra clave ocurre el cambio fuerte.
4. **Consecuencia:** el resultado queda a la vista.

Recursos que funcionan en cualquier tema:

- **Mecanismo:** algo real visto de costado o en corte.
- **Reconstruccion:** figuras simples viviendo el hecho.
- **Analogia:** lo abstracto como algo fisico (balanza, recipiente que se llena, fila de fichas).
- **Comparacion:** el mismo decorado en dos condiciones.
- **Cantidad que pesa:** muchos objetos se acumulan y su peso causa un efecto.
- **Descarte:** varias opciones se eliminan una por una y queda una.
- **Plano:** recorrido o evacuacion visto desde arriba.

## Metricas y graficos

Las metricas animadas resaltan lo importante. Se intercalan con los escenarios, nunca dominan: como mucho un tercio de las escenas y nunca dos seguidas. Cada una dura de 5 a 12 segundos y empieza con "GRAFICO: tipo".

Cada recurso se usa solo si cumple su ficha. Si no la cumple, no lo uses: un grafico que decora no explica nada.

| Recurso | Usalo cuando | NO lo uses cuando |
|---|---|---|
| big_number | Una cifra sorprende por si sola | La cifra es un detalle mas |
| versus | Dos cantidades reales se enfrentan | Son opiniones, o una cifra no existe |
| scale_compare | Hay que sentir el tamano de algo | No hay una referencia conocida |
| data_viz_single | Varias cantidades del mismo tipo | Son menos de 3 |
| line_chart | Un valor cambia en varios puntos conocidos | Solo hay un inicio y un final |
| timeline | 3 o mas hitos historicos con fecha, en orden | Es "desde tal ano hasta hoy", una duracion o un solo hecho |
| map_marker, map_globe | El lugar importa para entender | El lugar solo se nombra de paso |
| cycle_diagram | Hay un proceso que realmente se repite | Es una secuencia con principio y fin |
| layers_diagram | Algo tiene partes superpuestas reales | Es una lista de temas |
| pivot_question | Un giro fuerte, una vez cada varios minutos | Es una frase de transicion comun |

Antes de elegir, preguntate: si saco este recurso, se entiende menos? Si la respuesta es no, sacalo.

Solo datos que esten en el guion. Si el guion no trae cifras, no fuerces una metrica.

## Biblioteca visual del guion

Cada objeto se pide una sola vez y es el mismo en todo el video. Pedi solo lo necesario, con pocas piezas reutilizables. Lo que se mueve va separado de lo fijo. Los personajes son figuras simples con el esqueleto comun.
